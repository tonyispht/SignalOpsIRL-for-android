# Promo media

Images and videos for sharing Signal OPS IRL. Free to use for promoting the app.

| File | Size | Use |
|---|---|---|
| `banner.png` | 1280 × 640 | GitHub social preview, README header, website banner |
| `feature-1-scan.png` … `feature-4-level-up.png` | 1080 × 1080 | Instagram, Facebook, X, Reddit posts |
| `signal-ops-irl-trailer.mp4` | 1080 × 1920, 21 s | The official trailer, recorded in the app. TikTok, Instagram Reels, YouTube Shorts |
| `signal-ops-irl-promo.mp4` | 1920 × 1080, 23 s | YouTube, X, websites |
| `signal-ops-irl-promo-vertical.mp4` | 1080 × 1920, 23 s | TikTok, Instagram Reels, YouTube Shorts |

The phone screens are stylised illustrations of the app's interface, with generic example devices.

`source/promo.py` regenerates everything (Python + Pillow + ffmpeg). It uses the Orbitron, JetBrains Mono and VT323
fonts (SIL Open Font License), installed with `npm pack @fontsource/orbitron @fontsource/jetbrains-mono @fontsource/vt323`.
